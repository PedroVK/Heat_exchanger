# Descrição

O projeto será baseado em um projeto desenvolvido ao longo do semestre da disciplina de Operações Unitárias II.  
Esse projeto tem como objetivo ajudar a realizar os cálculos para o dimensionamento de um trocador de calor, utilizando os métodos de Kern e Bell-Delaware.  

## Fluxograma para o desenvolvimento

A primeira etapa do projeto será traduzir e compilar o apendice do kern, em um meio digital, para que possa ser utilizado, essencialmente utilizando uma tabela csv.  
Depois utilizar esse apendice para realizar os cálculos de forma interativa, para determinar um chute inicial, e depois fazer com que os valore venham a convergir utilizando as melhores condições para cada etapa, testando um N número de possibilidades.
